# HaloidCraft

**From silver to silicon.** Tools for black-and-white film and historic photographic processes, made by hand by Roy van Pelt.

### Products

**HaloidCraft Grain** — calibrated camera scanning for B&W film.
Calibrate your rig (lens, light, film base), convert in linear space, and print like a darkroom, with the grain kept honest.
*In development.*

**HaloidCraft Plate** — tools for dry plates and daguerreotypes.
*In development.*
